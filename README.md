# Деректер қоры — Электрондық оқу құралы

Автор: Найзағараева А.А. · Астана, 2026

Мобильді қосымшаға ұқсас электрондық оқу құралы (мұқаба, мазмұн, 15 дәріс, 15 практикалық жұмыс,
өзіндік жұмыс, бақылау материалдары, қосымшалар). Таза HTML/CSS/JS — сервер немесе орнату қажет емес.

## GitHub Pages арқылы жариялау

1. GitHub-та жаңа репозиторий жасаңыз (мысалы, `dereker-qory`).
2. Осы ZIP ішіндегі **барлық файлдарды** репозиторийдің түбіріне жүктеңіз
   (`index.html` түбірде тұруы керек). `.nojekyll` файлын да қосыңыз.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**
   → Branch: `main`, папка: `/ (root)` → **Save**.
4. 1–2 минуттан кейін сайт мына мекенжайда ашылады:
   `https://<аккаунт>.github.io/dereker-qory/`

## Мүмкіндіктер

- Мұқабада «Деректер қоры» атауын (жоғарғы жолақта) басқанда мұқабаға оралады.
- Бетті басқанда келесі бетке өтеді (бет аудару дыбысымен); бет шетінің сол жағын басу — артқа.
  Сондай-ақ «Келесі / Артқа» батырмалары, сипау қимылы және пернетақта көрсеткілері жұмыс істейді.
- Дыбысты жоғарғы жолақтағы белгіше арқылы өшіруге/қосуға болады (Тағы → Баптаулар).
- Тақырып бойынша және мәтін ішінен іздеу.
- Жарық/қараңғы тақырып, қаріп өлшемі, оқу барысы (құрылғыда сақталады).
- Телефонның басты экранына қосуға және интернетсіз ашуға болады (PWA).

## Файлдар

| Файл | Мазмұны |
|---|---|
| `index.html` | Мұқаба және қосымша құрылымы |
| `style.css` | Дизайн |
| `app.js` | Навигация, іздеу, дыбыс |
| `data.js` | Оқу құралының мәтіні (docx файлынан алынған) |
| `sw.js`, `manifest.json`, `icons/` | Офлайн режим және басты экранға қосу |
